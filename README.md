# stmstg
stg(shooting game) demo on stm32f407

it's just a demo and the code here is of great mass now.
this repository uses a simplified [u8g2 libarary](https://github.com/olikraus/u8g2.git) by myself, [freertos](https://www.freertos.org/) and some code generated by Stm32CubeMX.

this project uses usb keyboard to play the game.
