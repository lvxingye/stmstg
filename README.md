# stmstg
stg(shooting game) demo on stm32f407

It's just a demo and the code here is of great mass now.
This repository uses a simplified [u8g2 libarary](https://github.com/olikraus/u8g2.git) by myself, [freertos](https://www.freertos.org/) and some code generated by Stm32CubeMX.

This project uses usb keyboard to play the game and uses 0.96inch oled to display.

## running platform
[SkyStar(Tian Kong Xing) dev board](https://wiki.lckfb.com/zh-hans/tkx/hardware/explain.html) from [jlc](https://wiki.lckfb.com/en/).
This board has a STM32F407VGT6 MPU, a USB type-c port, a 10 pin SWD debug port, a SD slot, and an onboard SPI flash of 128Mb.

## pin connection
software I2C:  <br>
SCL -> PB4  <br>
SDA -> PB5  <br>
USB host port:  <br>
D-/DM  -> PA11  <br>
D+/DP  -> PA12  <br>
UART1:  <br>
RX  ->  PA10  <br>
TX  ->  PA9  <br>
